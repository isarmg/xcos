# xcos 1.0.3

## 自 1.0.2 以来的更新

- 录像列表及选中片段绑定查询摄像头和起止时间；切换摄像头、实例刷新替换摄像头或编辑日期时，在页面提交前隐藏旧结果，避免将上一台摄像头的片段时间拼入新摄像头的回放地址。
- 保留同一摄像头普通快照刷新时的录像选择，并继续忽略过期查询响应。
- 补充跨午夜、空日期、慢查询交错、切换时逐次渲染，以及浏览器媒体地址写入与请求回归。
- 软件与发行目录更新为 1.0.3；依赖、协议、数据库、配置及主码流录像范围保持不变。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xcos-1.0.3-x86_64-unknown-linux-gnu.tar.gz` 和 `SHA256SUMS`。

安装步骤见[部署指南](../getting-started.md)。
