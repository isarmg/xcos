# xcos 1.0.2

## 自 1.0.1 以来的更新

- 摄像头协调成功后正确持久化 source_on_demand=false，与实际持续拉流配置一致。
- PTZ 操作按最新待处理意图衔接，避免旧操作状态覆盖新请求。
- SSE 连接建立或恢复时刷新当前日志视图，补充摄像头操作回归测试。
- 修复日志刷新打断翻页后退回旧页面的问题，保留用户选择的目标页及翻页历史。
- Rust 与内嵌管理 Web 同步升级至 xcss 1.0.5，包含共享日志轮转和管理界面修复。
- 软件与发行目录更新为 1.0.2；协议、数据库与配置身份保持不变。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xcos-1.0.2-x86_64-unknown-linux-gnu.tar.gz` 和 `SHA256SUMS`。

安装步骤见[部署指南](../getting-started.md)。
