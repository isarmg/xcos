# xcos 1.0.0 发行说明与包内入口

本页记录历史发行归档；当前部署方式见[安装指南](../getting-started.md)。

软件版本为 `1.0.0`。程序、数据库结构、设备协议和媒体依赖分别标识；判断包内容时以完整源码 SHA、程序身份和 manifest 为准。
公开 v1.0.0 归档早于当前 `xcos-db-v2` 实现。本源码中的说明描述当前构建输入，不表示已有同名标签附件包含后续代码。

## 当前源码能力

- Rust 控制面管理摄像头实例、实时播放、录像查询、媒体操作和审计。
- 独立 xcoc 保存摄像头凭据，并向固定 MediaMTX 1.20.0 发布媒体。
- 管理页面嵌入服务端，公共支撑为 xcss 1.0.2 和一个构建期 `@xcss/web` 包。
- 当前数据库身份 `xcos-db-v2`、结构修订 2；浏览器身份 `xcos-wire-v2`，设备协议 `xcos-edge-v1`。

## 安装入口

历史归档不适用于当前部署规则。请使用当前源码对应的新发行包，并按[安装指南](../getting-started.md)执行包根 `install.sh --package PACKAGE --root ROOT --config CONFIG --public-key KEY --key-sha256 FINGERPRINT` 或 `upgrade.sh --root ROOT --version VERSION`；不迁移历史配置或发行布局。

## 源码与进一步阅读

正式打包需要干净源码、与软件版本一致且精确指向 HEAD 的 annotated tag。新的源码不能视为已经发布到原标签。
完整配置、服务管理、API 和开发测试见 [xcos 文档](https://github.com/isarmg/xcos/blob/main/docs/README.md)。选择与包内源码 SHA 对应的提交阅读。
