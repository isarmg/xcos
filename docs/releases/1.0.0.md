# XCOS 1.0.0

按本次明确授权重新建立发行基线：软件版本与标签分别为 `1.0.0` 和 `v1.0.0`；当前数据库身份为 `xcos-db-v1`、结构修订为 `1`，浏览器协议为 `xcos-wire-v1`，设备配对及媒体 JWT 契约为 v1。源码提交历史保留，旧 GitHub 标签、Release 和附件清除；新的发行包必须绑定本次完整源码修订和实际 SHA-256。

服务仅负责从已有绝对 ROOT 加载并校验配置和数据。安装、初始化、只读检查与离线凭据维护由独立 XSSI 脚本和同源 setup 辅助程序执行；升级由脚本协调 XSSC 停服、检查、备份、替换当前合同的程序并启动验收。不导入旧配置、迁移旧数据库或接受旧结构。

管理员凭据使用公共 SQLite 管理表与 Argon2id 哈希。配置由管理员控制，服务账号只读；业务状态和日志按最终服务沙箱授权写入。保留实例、文件、全局资源容量及登录尝试预算，不识别访问者 IP 或反向代理。公共传输日志与产品日志写入同一受管日志输出。

第三方 MediaMTX 的真实版本及外部 API 保持原义，发行包记录实际依赖、许可证原文与完整文件摘要。部署入口见[安装指南](../getting-started.md)，运行合同见[运行参考](../runtime-reference.md)。
