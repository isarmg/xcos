# xcos 1.0.1

## 自 1.0.0 以来的更新

- 摄像头观测区分当前、过期和未知状态，操作恢复说明与实际行为一致。
- 修复播放清理影响其他会话，以及摄像头查询失败后的页面恢复。
- 支持远程 HTTPS 入口，同时保留 MediaMTX 本地回调；验证可配置的 Caddy 上游默认值。
- 首段录像生成前返回空列表；实例改名后忽略已过期的客户端列表响应。
- Rust 与内嵌管理 Web 同步采用已验证并锁定的 xcss 1.0.2。
- 安装脚本、环境示例和生命周期测试同步使用 1.0.1 发行目录。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xcos-1.0.1-x86_64-unknown-linux-gnu.tar.gz` 和 `SHA256SUMS`。

安装步骤见[部署指南](../getting-started.md)。 本版使用 `xcos-db-v2` / revision 2；公开 1.0.0 归档使用更早的数据库格式，不支持直接覆盖旧库。媒体 JWT、设备协议与密钥派生合同保持不变。
